# Lomira Premium Design System (MASTER)

Target: Luxury Short Ankle Socks - Indonesian Market

## Design Thinking & Motif
- **Tone**: Luxury Refined / Performance Minimal
- **Style**: Soft UI Evolution + Glassmorphism
- **Key Pattern**: Hero-Centric + Social Proof + Truth-Focused Branding

## Color Palette (Luxury E-commerce)
- **Primary**: #2E7D32 (Deep Athletic Green) - Success, freshness, adem
- **Accent**: #A5D6A7 (Soft Mint) - Highlights, premium micro-details
- **Background**: #0F0F0F (Jet Black / OLED) - Luxury base
- **Card**: #1A1A1A (Graphite) - Subdued contrast
- **Text (P)**: #D1D5DB (Soft Silver) - High readability
- **Text (S)**: #9CA3AF (Muted Gray) - Secondary info

## Typography
- **Display**: Playfair Display (Serif) - Luxury, editorial, trust.
- **Body**: Plus Jakarta Sans (Sans) - Modern, clean, Indonesian aesthetic focus.

## Key Effects
- **Shadows**: Large blur, low opacity deep shadows (0, 50, 100, -20)
- **Transitions**: 500ms - 800ms ease-in-out for entry animations.
- **Micro-interactions**: 150ms spring transitions for hovers.

## Anti-Patterns to Avoid
- [ ] No "AI Purple" gradients.
- [ ] No generic Inter/Roboto fonts.
- [ ] No overstated shadows (must remain "Soft UI").
- [ ] No misleading long-sock imagery.

## Pre-Delivery Checklist
- [ ] Responsive check: 375px to 1920px.
- [ ] 100% Honest Product Shape (Short Ankle).
- [ ] Indonesian localized copy (Bahasa Indonesia).
- [ ] High-contrast accessibility for pricing.
