# Frontend Design Skill

This skill guides the creation of distinctive, production-grade frontend interfaces that avoid "AI slop" aesthetics. It prioritizes bold aesthetic directions, production-grade code, and meticulous attention to detail.

## Core Directives

1.  **Bold Aesthetic Commitment**: Before coding, choose an extreme (minimalist, maximalist, luxury, etc.) and commit to it fully.
2.  **Typography Excellence**: Avoid generic fonts (Inter, Roboto, Arial). Use distinctive display fonts paired with refined body fonts.
3.  **Color & Theme**: Direct and dominant color palettes with sharp accents. Use CSS variables.
4.  **High-Impact Motion**: Staggered reveals, scroll-triggered animations, and micro-interactions that surprise and delight.
5.  **Spatial Composition**: Use asymmetry, grid-breaking elements, and generous negative space.
6.  **Contextual Depth**: Use grain, noise textures, gradient meshes, and layered transparencies instead of solid backgrounds.

## Implementation Checklist

- [ ] Production-grade and functional code.
- [ ] Visually striking and memorable design.
- [ ] Cohesive aesthetic point-of-view.
- [ ] Meticulously refined details (spacing, shadows, borders).
- [ ] No generic AI aesthetics.
